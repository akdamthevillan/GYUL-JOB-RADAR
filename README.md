# 🍊 GYUL JOB RADAR

[웹사이트](https://akdamthevillan.github.io/GYUL-JOB-RADAR/) · [GitHub 저장소](https://github.com/akdamthevillan/GYUL-JOB-RADAR)

사람인(Saramin) 채용공고를 부산광역시 전체·경남 김해시·경남 양산시 대상으로 정리하는 웹사이트입니다.

## 검색 기준
- **지역**: 부산 전체 + 김해 + 양산. 기본 정렬은 사용자가 지정한 `사상구 → 부산진구 → 연제구 → 수영구 → ...` 순서입니다. 실제 통근 시간 순위와 동일하다는 의미는 아닙니다.
- **직무**: 디자인, 그래픽, 패키지, 편집, 브랜드, 웹, 마케팅, 기획, SNS, 콘텐츠, 온라인, MD 등.
- **경력**: 신입·경력무관(신입 포함)·필요 경력 2년 이하. 공고별 혼합 표기 시 원문 확인이 필요합니다.
- **업종**: 제한과 가산점 없음. 직무 관련성과 지역 기준으로 평가합니다.
- 정확한 설정: [data/search-config.json](data/search-config.json).

## 화면
- 회사명·직무·근무지·급여·복지·고려사항·접수상태·마감일을 카드에 표시합니다.
- 키워드/지역/직무 검색, 연봉·접수 검증 필터, 지역/추천/마감/신규 정렬.
- 중복 제거: 사람인 공고번호(가능하면) 또는 회사·직무·근무지 조합.
- 기한 경과·마감 확정 공고를 화면에서 제외.
- 관심/지원/숨김은 브라우저 내부에 저장됩니다.
- CSV 다운로드와 브라우저 내 공고 직접 추가.
- **업데이트 하기**는 ChatGPT에 미리 작성된 업데이트 요청을 새 창으로 열며, **사용자가 메시지를 전송해야** 요청이 실행됩니다. 버튼 자체가 서버의 수집을 실행하는 것은 아닙니다.

## 갱신
- 사용자가 ChatGPT에 요청하거나 한국시간 **매일 00:00 및 12:00**에 예약된 ChatGPT 작업이 공개된 사람인 공고를 검토하도록 설정되어 있습니다.
- 예약 작업의 GitHub 쓰기 권한, 사람인 검색 범위, 개별 공고 상태 검증에 따라 반영 가능한 내용이 달라집니다. **항상 성공하거나 전체 공고가 수집된다는 보장은 없습니다**.
- 공고 업데이트 시 ChatGPT가 연결된 GitHub 저장소의 `data/jobs.json` 및 `data/meta.json`을 수정하면 GitHub Pages는 자동 배포됩니다.
- 원문에서 확인한 폐쇄·기한 경과 공고만 삭제합니다. 검색 결과에서 안 보인다는 이유만으로 삭제하지 않습니다.
- 공개 검색 누락 또는 접근 제한 때문에 해당 시각에 모든 신규 공고와 접수 상태를 확인하지 못할 수 있습니다. 사전 허가 없는 사이트 직접 자동 크롤링은 실행하지 않습니다.
- GitHub Actions의 `on: push` 워크플로는 **배포 전용**이며, 사람인 수집은 실행하지 않습니다.

## 검토 기록
- 2026-10-16: 기존 목록을 초기화하고 직무/지역 조건에 맞는 15개 공고 등록 (부산 12건·김해 3건·양산 0건).
- 이 수치는 전체 인력시장 채용건수나 사람인 전체 공고수와 무관합니다.
