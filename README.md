# 🍊 GYUL JOB RADAR

[사이트](https://akdamthevillan.github.io/GYUL-JOB-RADAR/) · [GitHub Actions](https://github.com/akdamthevillan/GYUL-JOB-RADAR/actions)

부산·김해·양산 사람인 디자인/브랜딩/기획/마케팅/온라인/MD/SNS 공고 관리.

## 검색·정렬
- **직무/지역 기준**: 부산 전체·김해·양산, 사상구 → 부산진구 → 연제구 → 수영구 등 사용자 지정 정렬.
- **경력**: 연수 제한 없음. 신입부터 시니어까지 검색 대상. 각 카드에 정확한 모집 경력요건 표기.
- 회사 업종과 회사명에 따른 가산·제외 없음.
- 폐쇄 또는 마감일 경과가 확인된 **공고번호만** 삭제. 회사 전체 차단 없음.
- 중복 제거는 사람인 rec_idx, 보조로 회사+직무+주소.
- 현재 공고 확인 상태는 사람인 원문 기준. 검색 누락만으로 마감 판정하지 않음.

## 공고 카드
- 회사명, 직무, **주소(카카오맵 검색 링크)**, **냉정역(2호선) 출발 대중교통 소요시간**, 경력, 고용형태, 제시 연봉, 복지, 공고 등록일, 접수상태, 마감일 및 기타 주의사항.
- 사람인 기업정보가 확인되면 **매출·영업이익·평균연봉·사원수·최근 입사/퇴사 인원**을 출처 링크 및 기준 연도/기간과 함께 별도 표기. 기업 평균연봉과 모집공고 연봉은 구분.
- 공고 등록일을 확인하지 못한 경우 '원문 확인'. 목록에 수집된 날(first_seen)을 게시일로 대신하지 않음.
- 입력된 실제 대중교통 경로 조회 결과가 없으면 '소요시간 미확인'. 근거 없는 지역별 예상 시간을 생성하지 않음.
- 관심/지원 표시·숨김 및 직접 등록은 **현재 브라우저에만 저장**.

## 카카오맵 대중교통 경로 자동 계산 (선택 설정)
공식 Kakao Maps **REST API**에서 주소를 좌표로 변환하고, 냉정역 → 근무지의 대중교통 최단 소요시간을 조회하는 보조 도구를 포함함.

1. [카카오 개발자](https://developers.kakao.com/)에서 앱의 지도 REST API를 사용할 수 있도록 설정하고 키 발급 및 사용 가능 여부·쿼터 확인.
2. GitHub 저장소 `Settings → Secrets and variables → Actions → New repository secret`에서 이름 **`KAKAO_REST_API_KEY`**, 값 **REST API 키**로 등록. **공개 파일이나 채팅에 입력하지 말 것.**
3. [Enrich verified commute times](https://github.com/akdamthevillan/GYUL-JOB-RADAR/actions/workflows/commute.yml) 실행. 비밀키가 없으면 데이터를 변경하지 않음.
4. 이후 매일 **00:25 / 12:25 KST** GitHub Actions가 확인 가능한 경로를 갱신. 키 제한·주소 불일치·경로 없음이면 기존 데이터를 임의로 추정하지 않음.

공식 문서: https://developers.kakao.com/docs/ko/kakaomap/rest-api

## 모바일 사람인 기준 접수 상태 확인
- 각 카드의 **모바일 접수 확인** 버튼에서 해당 사람인 공고번호의 모바일 원문을 엽니다.
- 개별 공고에서 실제로 이용할 수 있는 **입사지원·채용 홈페이지·외부 홈페이지 지원** 등 지원 경로와 접수마감 표시를 함께 확인합니다. 온라인 지원 버튼이 없는 전화·우편·방문 방식도 있으므로 **버튼이 없다는 이유만으로 마감으로 분류하지 않습니다**.
- 검색 결과에 `입사지원`이라는 글자가 있다고 실제 버튼이 활성이라고 간주하지 않습니다. 로그인·자바스크립트·접근 제한으로 활성 상태가 보이지 않으면 `확인 불가`입니다.
- 검증 불가 상태는 모집 중으로 단정하지 않습니다. 접수 종료가 확인된 **공고번호만** 삭제하며 같은 회사의 다른 공고는 삭제하지 않습니다.
- 모바일 페이지의 직접 실시간 접근은 현재 이 대화의 조회 환경에서는 제한될 수 있고, 예약 점검도 모든 공고의 버튼 활성도를 보장할 수 없습니다.

## 공고 갱신
- ChatGPT 예약 점검: **매일 00:00 / 12:00 KST**, 사람인 공개 검색 후 GitHub 데이터 업데이트를 시도.
- 실제 원문 상태 검증/연동 권한에 따라 갱신 범위가 달라질 수 있으며 모든 공고 수집은 보장하지 않음.
- GitHub Pages는 `main`에 데이터가 바뀌면 자동 배포.
- GitHub Actions가 사람인 사이트를 무단 직접 크롤링하지는 않음.
- 사이트 '업데이트 하기' 버튼은 사용자가 ChatGPT로 갱신 요청을 보내는 링크이지, 브라우저에서 직접 갱신을 실행하는 기능은 아님.

## 파일
- `index.html`: 카드 UI·지도·필터·CSV
- `data/jobs.json`: 개별 공고와 선택적으로 검증된 기업정보·교통시간
- `data/search-config.json`: 업종 무관, 경력 제한 없음, 검색 키워드 및 지역순
- `data/closed-postings.json`: 마감 확정 **공고번호**만 보존
- `scripts/kakao_commute.py`: 카카오 공식 API 경로 조회
- `.github/workflows/commute.yml`: 카카오 경로 갱신 (키가 있는 경우)
- `.github/workflows/daily.yml`: GitHub Pages 배포

실명·연락처·개인 이력·개인 포트폴리오는 공개 저장소에 등록하지 않음. 사람인·카카오와 제휴한 서비스가 아님.
