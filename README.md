# 🍊 GYUL JOB RADAR

[사이트](https://akdamthevillan.github.io/GYUL-JOB-RADAR/) · [GitHub 저장소](https://github.com/akdamthevillan/GYUL-JOB-RADAR)

부산 전체·김해·양산의 사람인 디자인, 브랜딩, 콘텐츠, 기획, 마케팅, MD, SNS, 온라인 직무를 모아 보는 개인용 채용 대시보드.

## 화면
- 하나의 공고 목록. 회사명·직무·근무지 주소(카카오맵 길찾기)·경력·직무 연봉·복지·등록일·고용형태·기업정보를 카드에 표시.
- 검색, 지역·직무 필터, 지역 우선순·직무 추천순·신규순·마감순, 관심·지원 상태 표시.
- 확정 마감/기한 경과 공고는 숨김 및 제거. 회사 자체는 차단하지 않고 사람인 채용공고 ID 기준.
- 접수 여부는 **접수 확인**, **최근 모집정보(접수 미확인)**, **접수 미확인**으로 구분. 등록 건수가 모든 지역 공고 수를 뜻하지 않음.
- 사용자 요청에 따라 업데이트 버튼, 사람인 검색 바로가기, CSV, 수동 공고 추가, 안내문을 제거함.

## 갱신
- ChatGPT 예약 점검: 한국시간 매일 자정·정오 (예약 실행 환경의 검색·GitHub 연결 권한에 따라 실제 반영이 제한될 수 있음).
- GitHub Actions는 **push 시 Pages 배포만** 수행하며 사람인 크롤러가 아님.
- 공고 데이터 및 기준: [data/jobs.json](data/jobs.json) · [data/search-config.json](data/search-config.json) · [data/closed-postings.json](data/closed-postings.json).
- 방문자에게 즉시 갱신을 실행하는 기능은 구현하지 않음. 인증된 백엔드 없이 정적 Pages 버튼만으로 저장소를 안전하게 업데이트할 수 없기 때문.
- 카카오맵 링크는 출발지 냉정역, 도착지 공고 근무지 주소를 전달합니다. 좌표가 없는 공고는 이름/주소 기반 링크로 열려 모든 기기에서 자동 인식된다고 보장할 수 없습니다. API 키와 소요시간 계산은 사용하지 않습니다.
- 미확인 정보를 모집 중으로 단정하지 않고, 접수 가능 상태는 사람인 원문에서 확인해야 함.

실명·개인 연락처·포트폴리오를 공개하지 않습니다.
